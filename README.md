OrangeFox Recovery for Samsung Galaxy S20 FE 5G (r8q), only for the Snapdragon Variant.

OrangeFox is a Custom Recovery Project for Installing Custom ROMs, Rooting a device, and install OTA Updates.

Note - r8q is a A-Only Device

**How to Install** (For First Time Users)

1. Connect you phone with a laptop or computer.
2. Press the Volume Up and Volume Down Buttons Together.
3. Press the Volume Up Button.
4. Press the volume Up Button Again to unlock the Bootloader.
5. Let it boot back to One UI
6. Power off the phone and repeat steps 1-2 again.
7. Press Volume Down Button.
8. Download Odin3.
9. Install Samsung USB Drivers.
10. Download .TAR Fil from this Repository.
11. Load it in AP Slot in Odin
12. Click Start
13. When it reboots automatically press the Volume UP and the Power Button Together.
14. It will boot to OrangeFox Recovery.

**Your Device will boot to OrangeFox Recovery**
